## 🌌 What is WeatherNova?

**WeatherNova** is a modern weather intelligence dashboard designed to make weather data feel alive.

Search a city, use your location, switch between °C/°F, explore hourly and weekly forecasts, check air quality, and get simple weather insights — all through a polished glassmorphism interface.

> ☁️ **Search the sky.** &nbsp; 🌡️ **Read the atmosphere.** &nbsp; ✨ **Plan your day.**

---

## ✨ Experience the Dashboard

| Feature | What it does |
|---|---|
| 🔎 **Smart Search** | Search cities and load live weather data |
| 📍 **My Location** | Uses browser geolocation for local weather |
| 🌡️ **Live Conditions** | Temperature, feels-like, humidity, wind & pressure |
| ⏱️ **Hourly Forecast** | See the upcoming hours at a glance |
| 📅 **7-Day Outlook** | Plan ahead with an extended forecast |
| 🌿 **Air Quality** | PM2.5, PM10, ozone and AQI snapshot |
| 🧠 **Smart Insight** | Plain-English weather guidance |
| ☀️ **Sun Cycle** | Sunrise and sunset information |
| 🗺️ **Maps** | Open the selected location on OpenStreetMap |
| 🌓 **Theme System** | Smooth dark/light experience |
| °C/°F **Units** | Switch temperature units instantly |
| 📱 **Responsive UI** | Designed for desktop, tablet and mobile |

## 🛠️ Built With

- **HTML5** — semantic dashboard structure
- **CSS3** — glassmorphism, responsive layout, animations and visual effects
- **Vanilla JavaScript** — application logic and DOM interactions
- **Open-Meteo** — forecast, geocoding and air-quality data
- **Browser Geolocation API** — current-location weather
- **OpenStreetMap** — map/location view

### 🔑 No API key required

WeatherNova can be run directly in the browser using the Open-Meteo APIs.

---

## 🚀 Run Locally

### Option 1 — VS Code

Open the project folder in VS Code → install **Live Server** → right-click `index.html` → **Open with Live Server**.

### Option 2 — Python

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

> 📍 Browser location access works best through `localhost` or another secure context.

## 💡 Why WeatherNova?

Weather apps usually show numbers.

**WeatherNova tries to show the atmosphere.**

It combines useful weather information with a visual dashboard so users can quickly understand **what the weather is doing, how it feels, and what the day may look like.**
