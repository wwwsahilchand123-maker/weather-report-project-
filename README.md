# 🌦️ WeatherNova

> **Live Weather. A Better Tomorrow.**

WeatherNova is a futuristic responsive weather dashboard built with **HTML5, CSS3 and Vanilla JavaScript**. It uses the Open-Meteo APIs, so no API key is required.

## ✨ Features

- 🔎 Live city search and quick city buttons
- 📍 Browser geolocation
- 🌡️ Current temperature and feels-like temperature
- 💧 Humidity, wind, pressure, cloud cover and precipitation
- ⏱️ 12-hour hourly forecast
- 📅 7-day forecast
- 🌿 Air-quality snapshot
- ☀️ Sunrise and sunset
- 🧠 Plain-English smart weather insight
- 🌙 Dark/light theme
- °C / °F toggle
- 🗺️ OpenStreetMap location view
- ⚡ Responsive glassmorphism/neon UI
- 📱 Mobile navigation
- ⚙️ Working Settings and About modals

## ▶️ Run locally

Open the project in VS Code and run `index.html` with **Live Server**, or use:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## 🌐 APIs

- Open-Meteo Forecast API
- Open-Meteo Geocoding API
- Open-Meteo Air Quality API

No API key is required.

> Weather information is intended for education/demo use and should not be treated as safety-critical forecasting.
