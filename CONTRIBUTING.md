# Contributing to Weather Report Project

Thanks for helping improve the weather-report project.

## Guidelines

- Keep UI changes responsive and accessible.
- Do not commit API keys or private configuration; use environment variables or an example config.
- Keep weather-provider logic separate from presentation where practical.
- Test loading, error, and empty-data states when changing the weather UI.

## Pull requests

Describe the change, testing performed, and any new configuration or API requirements. Keep screenshots or demo assets focused on the feature being changed.
